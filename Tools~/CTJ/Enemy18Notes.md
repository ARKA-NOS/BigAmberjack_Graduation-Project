# Enemy18 폐액 도약충

기획 ID는 `enemy_effluent_leaper`다. Toxcrawler의 대기·달리기·상승·낙하·공격·사망 시트를 공통 발 기준점으로 슬라이스했다. 등에 폐액통과 관을 얹고, 준비 중에는 몸을 낮추도록 했다. [09-18 폐액 도약충 기획서](https://app.notion.com/p/09-18_-4189e7231ca7819ca6a1dd910dae0e13)

| 항목 | 프리팹 설정 |
| --- | --- |
| 체력·방어 | 체력 65, 방어 2 |
| 이동 | 3.4유닛/초, 8유닛 안에서 추격, 11유닛 초과 시 스폰 지점으로 복귀 |
| 피격 | 경직 0.25초, 기존 일반 적의 넉백과 피격 이펙트 |
| 도약 준비 | 플레이어와 2~3.5유닛 거리에서 착지 지면과 경로가 확보되면 0.6초간 몸을 낮춤. 2유닛보다 가까우면 먼저 후퇴 |
| 도약 | 준비 자세에 들어갈 때 플레이어 위치에서 착지점을 구해 고정. 붉은 원으로 착지 피해 범위를 표시 |
| 착지 | 실제 접촉 지점을 기준으로 폐액을 튀김. 반경 0.85유닛에서 피해 12를 한 번 판정 |
| 다음 행동 | 착지 후 0.75초 동안 회복 자세 유지. 착지부터 계산한 3초 쿨타임 동안 회복이 끝나면 4.25유닛/초로 후퇴. 목표 거리는 8유닛이며 쿨타임 종료 후 다시 추격 |
| 처치 보상 | 코인 5~8골드, 기존 혈흔 버스트와 사망 페이드 재사용 |

도약 직전에는 고정된 착지점의 지면이 아직 유효한지 검사한다. 착지점 높이 차이는 최대 0.8유닛이다. 붉은 원은 준비부터 착지까지 유지하고, 공격이 중단되면 숨긴다. 최소 거리를 조정할 때는 `SkillModule`의 **Min Range**와 `KeepDistanceModule`의 **Minimum Distance**를 같은 값으로 맞춘다. **Cooldown Retreat Distance**와 **Cooldown Retreat Speed Multiplier**로 후퇴를 조정할 수 있다. 후퇴 목표 거리는 추적 해제 거리에서 0.75유닛을 뺀 값으로 제한한다. 벽이나 절벽에 막히면 현재 위치에서 멈춘다. 기획의 경험치 12는 프로젝트에 지급할 경험치 시스템이 확인되지 않아 연결을 보류했고, 1스테이지 배수·발판 구간 배치는 맵 작업으로 남아 있다.

## 직접 테스트

1. `EnemyTestScene`에서 플레이어와 같은 평평한 `Ground` 발판에 `Enemy18_EffluentLeaper`를 2유닛보다 가까이 배치한다. 먼저 물러나 2유닛 이상 간격을 확보한 뒤 몸을 낮추는지 확인한다.
2. 준비 자세에 들어가면 보이는 붉은 원 밖으로 이동한다. 준비 중과 비행 중에 원이 처음 위치에 유지되고, 적은 원에 표시된 위치로 떨어진다. 착지점에 그대로 서면 착지 순간 한 번 피격된다.
3. 발판 가장자리나 낮은 천장 아래에서 유도한다. 발이 걸칠 바닥이 없거나 경로가 막히면 도약이 시작되지 않는다.
4. 착지 후 0.75초가 지나면 빠르게 멀어지고, 착지부터 3초가 지나면 다시 추격하는지 확인한다. 처치 후에는 활성 `GameManager`가 있는 씬에서 코인 5~8골드를 확인할 수 있다.

격리 Play Mode에서 준비 중 플레이어가 추적 해제 거리 밖으로 움직여도 착지점이 고정되는지 확인했다. 출발부터 착지까지의 경고, 지름 1.7유닛의 원 메쉬, 쿨타임 중 후퇴와 종료 후 재추격도 검사했다.

## 사용한 문법과 이유

- `out`으로 경로 검사에서 계산한 도약 궤적과 착지점을 함께 받는다. 성공한 궤적을 그대로 물리 스텝에서 사용하므로 검사한 경로와 실제 이동이 맞는다.
- `[SerializeField]`로 경고 표시와 쿨타임 후퇴를 프리팹에서 고른다. 후퇴 규칙은 연결한 도약 스킬의 `RemainingCoolTime`을 읽는다.
- `distanceSquared`를 최소 거리의 제곱과 비교해 후퇴가 필요한지 판단한다. 같은 2D 거리 기준을 스킬의 **Min Range**와 맞춰 가까이 있을 때 도약이 시작되지 않도록 한다.
- `ContactFilter2D`로 지면과 발판을 걸러 실제 접촉한 경우에만 착지 애니메이션과 파티클을 재생한다. 도약 중에는 Rigidbody2D의 중력을 보관했다가 착지하거나 공격이 끝날 때 복구한다.
- `ParticleSystem.MinMaxCurve`로 폐액 방울마다 속도와 크기를 조금씩 다르게 뽑는다. 재생과 제거는 기존 `EnemyParticleModule`과 `EnemyHitParticle` 경로를 사용한다.
