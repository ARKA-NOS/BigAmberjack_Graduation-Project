# Enemy23 자연스러운 모션과 반격 시간

최신 기본 자세·단발 섬광·공중 부유·폭격 이동은 **[Boss23GifReferenceNotes.md](Boss23GifReferenceNotes.md)**를 참고한다. 아래의 반격 시간과 기존 이동 방식은 계속 사용하며 강화 설정은 그대로다.

작업일: 2026-11-24. 이번 변경은 앞선 고정 타임라인에 애니메이션을 억지로 맞춘 설정을 대체한다. 기존 FSM·스킬·비행·비주얼 모듈을 수정했으며 새로운 패턴 시스템이나 매니저는 만들지 않았다.

## 공격 후에는 먼저 기본 자세로 복귀

- 돌진 스프라이트는 이동 시간에 맞춰 늘리지 않고 **2배속**으로 재생한다. 돌진 이동이 끝나면 바로 Idle로 돌아간다. 강화 재조준 대기도 Idle 자세를 사용한다.
- 충전은 원본 **1배속 / 강화 1.2배속**으로 재생한다. 원본 Charge 클립 길이 약 0.545초에 맞춰 충전 구간을 일반 0.55초, 강화 0.46초로 직접 조정했다.
- 연사는 일반 **1.2배속**, 강화 **3배속**으로 발사 모션을 재생한다. 마지막 모션이 끝나면 바로 Idle에서 후딜을 시작한다. 예전처럼 별도의 회복 시작 시각까지 공격 마지막 프레임을 붙잡지 않는다.
- 같은 애니메이션을 다시 재생한 프레임에는 이전 재생의 완료 상태를 읽지 않도록 했다. 이 보정이 없으면 마지막 연사·폭탄 발사 모션을 재생하자마자 완료로 판단해 잘라 버릴 수 있다.
- 클립 길이를 읽어 지정 시간에 강제로 늘리는 PlayForDuration은 사용처와 함께 제거했다. 이번에는 기존 스킬의 수치·분기와 고정 재생 속도를 직접 맞췄다.

## 이동과 공중 전환

기본 지상 이동은 2.4유닛/초를 유지하고, 공중 상승·하강은 별도 **최고 속도 10**으로 조정했다. 강화 상승은 1.2배인 12를 사용한다.

FlightModule의 기존 가속·감속 방식으로 **0.18초** 동안 출발과 정지를 연결한다. 시간 지정 돌진에도 같은 방식을 적용한다. 비주얼은 기존 DroneVisualModule에서 매 렌더 프레임에 Lerp로 보간해 FixedUpdate 위치 갱신이 화면에서 계단처럼 보이는 것을 줄였다. 콜라이더와 피해 판정은 원래 물리 위치를 사용한다.

공중 전환은 Rise → 빠른 상승 → **도착 즉시 조준 사격** → AirIdle 후딜 순서다. 이전의 사격 전 0.15초 대기는 사격 모션 뒤로 옮겼다. 비행 변형 자체는 원본 모션의 길이대로 진행한다.

폭격도 마지막 Bomb 모션이 끝나면 바로 빠르게 하강한다. 예전 5.5초·7초 종료 시각을 기다리지 않는다. 착지하면 Idle로 돌아가고, 이미 투하한 폭탄들이 모두 착탄한 뒤 패턴을 종료한다. 표식 이후 폭발까지의 1.65초/1.15초와 투하 간격·피해·반경은 계속 적용한다.

## 각 패턴 사이의 반격 시간

기존 FSM의 **Recover** 상태를 공통으로 사용한다. 지상 패턴 종료, 공중 전환의 사격 종료, 레이저 후 착지, 폭격 종료 후에는 **1.25초 동안 기본 자세에서 정지**한다. 이때 새 공격을 시작하지 않고 정상적으로 피해를 받는다. 공중 전환 후에는 AirIdle로 쉬고, 그 뒤 공중 패턴 선택으로 이어진다.

35% 진입용 상승·편도 레이저는 하나의 진입 패턴이므로 도중에 새 휴식을 끼우지 않는다. 공격을 마친 뒤에는 같은 회복을 사용한다. 강화 레이저의 두 횡단 사이 0.25초 대기는 같은 패턴 내부의 대기다.

## 직접 테스트

1. EnemyTestScene에서 Enemy23과 플레이어를 활성화한다. 아레나와 바닥 설정, 중앙 위 공중 공간을 확보한다.
2. 추적 돌진의 스프라이트 전환이 빨라졌는지, 돌진 종료 직후 기본 자세로 돌아오는지 본다. 연사도 마지막 발사 모션 후 기본 자세에서 쉬어야 한다.
3. 패턴 종료 후 약 1.25초 동안 가까이 가서 공격한다. 보스가 멈춰 있고, 새 패턴을 즉시 시작하지 않으며 HP가 줄어야 한다.
4. 상승·하강의 처음과 끝이 부드러운지, 고도 도착 후 사격 전 빈 대기가 없는지 확인한다. 사격 후 쉬는 동안에는 AirIdle이어야 한다.
5. HP를 35% 이하로 내려 같은 조건을 강화에서도 확인한다. 폭격은 마지막 발사 후 내려와 쉬며, 날아가는 폭탄은 계속 착탄해야 한다.

## 사용한 문법과 이유

- **Vector3.Lerp와 지수형 보간 계수**: `1 - Exp(-속도 × deltaTime)`으로 비주얼을 보간해 렌더 프레임 속도에 따른 차이를 줄인다. 별도 이동 시스템을 만들지 않고 기존 LateUpdate에 적용했다.
- **기존 enum Recover와 bool**: 공중 휴식 뒤 공중 선택으로 이어갈지 지상 선택으로 이어갈지만 구분한다. 기존 회복 상태를 재사용한다.
- **Animator 재생 속도와 완료 확인**: 클립은 명시한 배속으로 끝까지 재생하고, 마지막 발사 모션이 끝나면 Idle로 전환한다. 공격 시간에 맞춰 자동으로 클립 길이를 늘리지 않는다.
- **Time.frameCount**: Animator.Play를 호출한 프레임에 이전 재생의 완료 상태를 읽는 문제를 막는다.
- **FormerlySerializedAs**: 기존 사격 전 대기 값을 Post Attack Delay로, 기존 공중 회복 값을 Pattern Recovery Time으로 옮기면서 직렬화 참조를 유지한다.

프리팹에 현재 조정값을 다시 연결하는 도구는 **SetupBoss23Timeline.UpdateMotion**이다.
