# Enemy17 흡기구 파쇄충

기획 ID는 `enemy_intake_biter`다. Night Fang의 원본 PNG를 슬라이스하고, 등 쪽 흡기구는 별도 픽셀 스프라이트로 붙였다. 원본 시트에서 빔이 나오기 직전의 턱 동작을 물기 프레임으로 사용했다. [09-17 흡기구 파쇄충 기획서](https://app.notion.com/p/09-17_-4189e7231ca781429a45cc9ae7ff3c3f)

## 프리팹 설정

| 항목 | 값 또는 담당 모듈 |
| --- | --- |
| 체력 및 방어 | `NewHealthModule`과 `Enemy17_IntakeBiter_Stats`로 체력 45, 방어 1 |
| 이동 | 배회·추격 속도 2.8유닛/초, 감지 7유닛, 추적 해제 10유닛 초과 |
| 복귀 및 배회 | 스폰 지점 X로 복귀 후 좌우 3유닛 배회. 절벽·벽 때문에 갈 수 없으면 안전한 쪽에서 배회 |
| 물기 | 1.2유닛 안에서 멈춰 준비 0.45초. 0.16초에 입을 크게 벌리고 발동까지 유지한다. 발동과 함께 입을 닫고, 준비가 시작된 방향 정면에 0.08초 동안 피해 8을 최대 한 번 적용 |
| 공격 간격 | 판정이 끝나면 후딜 0.65초. 쿨타임 1.6초는 실제 타격 시각 기준. 빗나가면 공격 발동 시각 기준 |
| 피격 | 경직 0.25초, 기존 일반 적 넉백 값, 준비 중 피격 시 취소, 전용 피격 프레임과 기존 점멸·혈흔·데미지 표시 |
| 사망 | 마지막 타격 프레임에 사망 애니메이션 시작. 혈흔 버스트와 끝 프레임 페이드아웃 재사용 |
| 보상 | 기본 3골드에 0~2골드 추가. 기존 코인으로 분배해 자동 획득. 기획의 경험치 8은 연결할 경험치 시스템이 확인되지 않아 보류 |

`EnemyPatrolModule`의 **Return To Spawn Before Patrol**을 켰다. `Bite`의 **Lock Facing During Preparation**, **Cooldown From Strike**를 켰다. `CurrencyRewardModule`의 **Max Bonus Amount**는 2다. 배회 정지 간격은 원본으로 삼은 근접 적 프리팹의 3초를 사용한다. 수치는 프리팹의 각 모듈에서 조정할 수 있다.

## 직접 테스트

1. `EnemyTestScene` 또는 플레이어와 `GameManager`가 있는 테스트 씬을 연다. 여러 시나리오를 볼 수 있도록 `Ground` 레이어의 평평한 바닥에 `Enemy17_IntakeBiter`를 하나 배치한다. 추격 해제 테스트에는 양쪽으로 10유닛 넘게 이동할 공간이 필요하다.
2. Play에서 7유닛 안으로 접근해 추격을 시작시키고, 거리를 7~10유닛으로 벌려도 계속 쫓는지 본다. 적과 10유닛 이상 떨어진 뒤에는 스폰 위치로 돌아오고 잠시 멈췄다가 그 좌우에서 배회한다.
3. 같은 발판에서 1.2유닛 안으로 들어가 물기를 유도한다. 입을 벌린 동안에는 피해를 받지 않고, 정면에 그대로 있으면 입을 닫는 순간 한 번 피해를 받는다. 준비 동작 중 뒤로 넘어가면 적은 처음 방향에 물기를 사용한다.
4. 준비 중 타격하면 물기가 취소되고 피격 그림·경직이 나온다. 처치 시 같은 프레임부터 사망 그림으로 전환하고, 혈흔 버스트가 보인다. 코인 1~2개가 떨어진 뒤 플레이어에게 모이며 총 3~5골드가 들어온다. 처치 수까지 확인하려면 활성 `EnemyKillCountManager`를 씬에 둔다.

격리 Play Mode에서 감지 및 추적 해제, 스폰 지점 복귀와 배회 재개, 뒤로 넘어가 회피, 단발 피해, 쿨타임, 방어·경직·피격 그림, 사망 페이드와 처치 수, 코인의 자동 지급을 검사했다. 기획의 배치 장소인 1스테이지 공장 입구 복도는 실제 맵에 배치할 때 적용한다.

## 사용한 문법과 이유

- `[SerializeField] private`으로 공용 모듈의 선택 옵션을 Inspector에 노출했다. 기본값을 `false` 또는 `0`으로 두면 기존 프리팹도 같은 모듈을 그대로 사용할 수 있다.
- `override OnUseSkill()` 안에서 `base.OnUseSkill()`을 호출해 공용 스킬 초기화와 준비 처리를 사용한다. 타격 기준 쿨타임을 쓰는 경우에만 이전 시작 시각을 복원한 뒤 실제 타격 시각을 기록한다.
- `Vector2.Dot`의 부호로 대상이 저장된 공격 방향의 앞쪽에 있는지 판단한다. 플레이어 콜라이더가 턱 판정에 걸쳐 있어도 중심이 뒤쪽이면 빗나간다.
- `Random.Range(int, int)`의 상한은 제외된다. 0부터 보너스 최대치까지 모두 나오도록 상한에 1을 더한 후 기존 코인 분배 경로로 넘긴다.
- `SpriteRect.pivot`을 셀 안의 공통 발 기준점으로 맞춰 프레임 사이에서 모델이 튀는 일을 막았다. `ObjectReferenceKeyframe`은 정해진 시각에 `SpriteRenderer.sprite` 참조를 바꾼다. 같은 방식으로 피격과 사망 중에는 흡기구 참조를 `null`로 바꿔 숨긴다.
- 입을 벌린 스프라이트를 준비 클립 마지막까지 유지했다. 타격 처리에서 호출하는 `Animator.Play`는 공격 상태의 0초부터 시작하므로, 0초 키에 입을 닫은 스프라이트를 넣으면 같은 게임 프레임에 물기 자세와 판정이 시작된다.
