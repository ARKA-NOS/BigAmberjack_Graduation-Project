# 피격 전용 아웃라인 · 화면 픽셀 두께 · 코인 펀치 강화

2026-11-05 후속 수정. 수정은 `Assets/CTJ` 안에서 진행했습니다.

## 현재 설정

여섯 적의 `OutlineModule → EnemyOutlineModule → Show Only When Hit`를 켰습니다.

- 켜짐: 평소 숨김 → 실제 HP가 감소하면 어두운 빨강으로 0.25초 표시 → 다시 숨김.
- 꺼짐: 평소 검정 → 피격 시 어두운 빨강 → 0.25초 뒤 검정으로 복귀.
- 연타하면 마지막 피격부터 시간이 다시 계산됩니다. 회복은 표시 시간을 늘리지 않습니다.
- 치명타도 마지막 피격 연출 동안 표시할 수 있으며, 이후 사망 애니메이션에는 남지 않습니다.

| 항목 | 값 |
| --- | --- |
| Normal Color | 검정 #000000 |
| Hit Color | 어두운 빨강 #BF2E38 |
| Width | 최종 출력 화면 기준 2픽셀 |
| Hit Duration | 0.25초 |
| Show Only When Hit | 켜짐 — 테스트 후 끄면 검정 상시 표시 |

피격 블링크 #FF525C보다 어두운 빨강을 테두리에 사용합니다. 색과 두께는 기존 인스펙터 필드에서 계속 조절할 수 있습니다. 코드에서는 `outline.ShowOnlyWhenHit = false;`처럼 모드를 전환할 수 있습니다.

## 두께 문제를 확인한 결과

기존 셰이더도 가로/세로 경계는 화면 픽셀 기준이었습니다. 원본 크기가 16×16인 그림과 256×256인 그림에서 카메라 Orthographic Size를 1/2/4로 바꾸어도 Width=2는 2픽셀이었습니다.

반면 대각선은 `dx + dy`를 사용해서 같은 Width라도 검사 거리가 √2배 길었습니다. 그래서 경계의 기울기나 모델 모양에 따라 더 두껍게 보일 수 있었습니다. 이를 **동일한 반지름의 16방향 검사**로 변경했습니다. 가까운 거리부터 검사하므로 얇은 런처나 받침을 건너뛰지 않습니다.

`ddx/ddy`로 구한 내부 렌더 타깃 픽셀 크기를 `_ScaledScreenParams / _ScreenParams` 비율로 최종 출력 픽셀에 환산합니다. 바깥 테두리용 메시 확장도 출력 해상도를 기준으로 합니다. 실제 픽셀은 정수 격자이므로 대각선 경계에는 1픽셀 정도의 계단 차이가 생길 수 있습니다. 45° 경계의 6픽셀 두께를 가로로 가로질러 재면 약 8.49픽셀이므로 8~9픽셀이 정상입니다.

**Unity Game 뷰의 Scale 슬라이더는 완성된 화면을 확대하는 기능**입니다. 2배 확대하면 게임의 모든 픽셀과 테두리도 화면에서 2배로 보입니다. 두께 비교는 Game 뷰 Scale을 1x로 두고 게임 카메라의 줌을 바꿔 확인하세요. 이번에 재현된 문제는 대각선 검사 거리 차이이며, 사용자가 보았던 확대 현상이 Game 뷰 확대였는지는 확인되지 않았습니다.

기존 SpriteMask 처리와 터렛의 합쳐진 바깥 실루엣 규칙은 유지합니다.

## 직접 테스트

1. CTJ 테스트 씬에서 적을 타격하기 전 아웃라인이 숨겨지는지 확인합니다.
2. 적을 한 번 때립니다. 어두운 적색 테두리가 잠깐 나타나고 사라져야 합니다. 연속 타격에서는 마지막 타격 뒤까지 유지됩니다.
3. Play 중 OutlineModule의 Show Only When Hit를 끕니다. 평소에는 검정, 피격 중에는 어두운 적색이어야 합니다.
4. Width를 같은 값으로 놓고 적의 Transform Scale과 카메라 Orthographic Size를 바꾸어 비교합니다. Game 뷰 Scale은 1x로 맞춥니다.
5. 터렛을 회전/수납하여 바깥 테두리가 이어지고 겹친 파츠 내부에는 선이 생기지 않는지 봅니다.
6. 적을 처치하고 플레이어에게 도착하는 코인의 확대·축소가 더 분명한지 봅니다. 미세 조정은 코인 프리팹의 Collect Scale 세 항목에서 합니다.

- 여섯 실제 적에서 피격 전 숨김, 적색 표시, 타이머 갱신, 회복 제외, 검정 상시 모드, 활성화/제거 처리 통과.
- 좀비 치명타의 마지막 피격 중 표시 후 사망 연출에서 제거되는 것 확인.

## 사용 문법과 이유

- **bool 직렬화 필드와 프로퍼티**: `showOnlyWhenHit`는 인스펙터 저장값, `ShowOnlyWhenHit`는 다른 코드에서 테스트 모드를 바꾸는 진입점입니다. 새 인터페이스는 필요하지 않습니다.
- **조건식으로 SpriteRenderer.enabled 제어**: 숨김 상태에는 렌더러를 꺼 화면에 그리지 않습니다. HP 변경 이벤트와 기존 타이머를 재사용합니다.
- **HLSL의 ddx / ddy**: 화면 가로/세로 한 픽셀 이동에 대응하는 UV 변화량입니다. 스프라이트 해상도와 월드 스케일에 의존하지 않는 두께의 기준이 됩니다.
- **단위 벡터 배열**: 16개 방향의 길이를 모두 1로 맞추고 Width를 곱합니다. 대각선 벡터 (1,1)의 길이가 √2라 더 굵어지던 차이를 없앱니다.
- **min/max 알파 누적**: 주변의 가장 작은 알파로 안쪽 경계를 찾고, 가장 큰 알파로 바깥 경계를 찾습니다. 원본 머티리얼이나 그림을 수정하지 않습니다.
- **MaterialPropertyBlock**: 같은 머티리얼을 쓰면서 적별 두께·UV 범위·안팎 표시 방식을 전달합니다. 색은 SpriteRenderer.color로 전달하며, 피격 때마다 머티리얼을 복제하지 않습니다.
- **코인 값 조정**: 기존 Lerp/SmoothStep 연출을 재사용하고 확대·축소 배율과 시간만 조정했습니다.
