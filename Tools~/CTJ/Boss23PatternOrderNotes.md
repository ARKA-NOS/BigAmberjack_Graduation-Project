# Enemy23 패턴 순서 고정

작업일: 2026-11-26.

## 동작

일반·발악 상태 모두 아래 순서로 반복한다.

**추적 → 연사 → 공중 전환 → 사선 레이저 → 추적 → 연사 → 공중 전환 → 척탄 → 처음부터**

기존 `DroneBombSkill`의 표적 폭격이 여기서 말하는 척탄이다. 강화 상태에서는 같은 순서에서 각 스킬의 기존 강화 동작을 사용한다. HP 35% 이하 진입 연출·보호막·낙하·그로기는 별도 처리로 유지하며, 그로기 회복 후에는 강화 추적부터 순환한다.

`ProductionControlDrone`의 기존 FSM에서 선택 방식만 변경했다. 지상은 추적·연사·공중 전환의 세 차례를 반복하고, 공중 공격은 사선 레이저·척탄을 교대한다. 지정된 차례가 쿨타임 중이거나 실행에 실패하면 다른 패턴으로 건너뛰지 않는다. 상승 전에도 이번 차례의 공중 공격이 가능한지 확인한다. 기존 후딜·반격 시간·중앙 복귀와 스킬 데이터는 유지한다. 추가 인스펙터 연결은 필요 없다.

## 직접 테스트

1. `Assets/_Scenes/Test/EnemyTestScene.unity`에서 플레이어와 Enemy23을 활성화해 실행한다. 플레이어가 보스의 추적 범위 안에 있도록 유지한다.
2. 일반 상태에서 위 8개 행동을 관찰한다. 첫 공중 전환 뒤에는 사선 레이저, 두 번째 공중 전환 뒤에는 척탄이 나와야 한다. 척탄이 끝나면 추적으로 반복해야 한다.
3. HP를 35% 이하로 낮춘다. 기존 발악 진입 연출과 그로기가 끝나면 강화 추적으로 시작하고, 동일한 순서를 반복해야 한다.

## 검증

실행 도구는 `VerifyBoss23Rework.RunNormalPatternOrder`와 `RunEnhancedPatternOrder`다. 테스트 씬에서 실제 FSM과 스킬을 진행시키며 8단계 후 다시 추적이 시작되는 시점까지 관찰한다. 검증 중에만 시간을 2배속으로 진행하고 종료 시 원복한다. 보스의 패턴 시간 설정은 바꾸지 않는다.

- 일반·강화 모두 실제 9개 스킬 시작 순서가 `추적, 연사, 공중 전환, 사선 레이저, 추적, 연사, 공중 전환, 척탄, 추적`과 일치하는지 확인한다.
- 지상 3개 차례·공중 2개 차례·상승 전 공중 쿨타임 2개 조건에서 총 7회, 순서가 건너뛰어지지 않는지 검사한다.
- 순환 도중 HP 35% 이하에 진입할 때 다음 순서가 강화 추적·첫 공중 레이저로 초기화되며, 기존 무적 진입 연출을 거치는지 검사한다.

측정 결과: [일반·쿨타임·발악 진입](Boss23NormalPatternOrderVerification.json), [강화 순환](Boss23EnhancedPatternOrderVerification.json).

모두 통과했다. 일반은 게임 시간 약 33.34초, 강화는 약 32.14초에 다음 순환의 추적이 시작됐다. 총 7개 쿨타임 조건과 발악 진입 초기화 검사도 통과했으며, 게임 컴파일 오류·경고는 0이었다. 씬 파일은 저장하거나 변경하지 않았다.

## 사용한 문법과 이유

- `switch` 식: 지상 차례 0·1·2에 대응하는 스킬을 선택한다. 무작위 후보 목록을 만들 필요가 없다.
- 나머지 연산 `% 3`: 지정 실행이 성공한 뒤에만 지상 차례를 `0 → 1 → 2 → 0`으로 진행한다.
- 논리 부정 `!`: 공중 공격 시작이 성공하면 사선 레이저·척탄 차례를 서로 뒤집는다. 지상 세 단계와 합쳐 요청한 8단계가 된다.
- 기존 `Ready` / `TryUseSpecifiedSkill`의 반환값: 기존 쿨타임·참조·실행 조건을 통과한 경우에만 차례를 넘겨, 실패했는데 다음 공격이 나오는 문제를 막는다.
