# Enemy23 최종 수치·패턴 타임라인 조정

이 문서는 고정 타임라인을 맞추던 이전 단계의 기록이다. 현재 동작·대기 시간·공중 속도는 **[Boss23MotionNotes.md](Boss23MotionNotes.md)**를 따른다. 아래의 4초/7초 같은 총 시간과 PlayForDuration 설명은 현재 구현에 적용되지 않는다.

작업일: 2026-11-24. 이번 문서는 직전 1.5초 연사·재경고 레이저 설정을 대체한다. 노션과 EnemyTestScene 파일은 수정하지 않았다.

## 공통 규칙

- 기본 지상 이동·후퇴·상승·일반 하강은 **2.4유닛/초**를 최고 속도로 사용한다. 기존 빠르게 시작하고 느려지는 이동 곡선을 유지한다.
- 시간이 별도로 지정된 돌진과 폭격 패턴의 하강은 해당 타임라인에 맞춰 이동한다. 예를 들어 6.5유닛 돌진을 1.3초 안에 마치려면 일반 이동보다 빠른 속도가 필요하다.
- Enemy23은 실제 HP 피해와 점멸·파편·데미지 표시를 받지만, 피격으로 인한 **넉백·경직·공격 취소·Hurt 애니메이션 전환**은 받지 않는다. 프리팹 설정과 ProductionControlDrone.ModifyIncomingDamage의 suppressHitControl로 함께 보장한다. 새 무적 상태를 추가한 것은 아니다.
- 추적과 연사는 패턴 시작 때 바라보는 방향을 고정한다. 강화 추적의 **1.99~2.33초 재조준 구간에서만** 방향을 다시 맞추고, 두 번째 돌진이 시작되면 고정한다.
- 지상 3개 → 공중 2개 무작위 선택과 HP 35% 진입용 기존 편도 레이저 1회는 계속 사용한다. 진입용 상승에는 추가 사격을 하지 않는다.

프리팹: `Assets/_Prefabs/Enemies/Bosses/Enemy23/Boss23_ProductionControlDrone.prefab`

## 추적 — SkillModule / Charge

피해량 **일반 18 / 강화 22**, 돌진 1회당 최대 한 번이다. 돌진 거리는 6.5유닛이며 벽·절벽·아레나 경계가 막으면 가능한 구간까지만 이동한다. 각 돌진은 도착할수록 감속한다. 돌진 중에는 CrouchFire와 부드러운 잔상을 사용하고, 충전에는 기존 Charge 애니메이션, 자세 복귀에는 역순 CrouchRecover를 사용한다.

| 단계 | 일반 | 강화 |
| --- | --- | --- |
| 추적 이동 | 0~1.15초 | 0~0.74초 |
| 충전 | 1.15~2.05초 | 0.74~1.31초 |
| 1차 돌진 | 2.05~3.35초 | 1.31~1.99초 |
| 재조준 | 없음 | 1.99~2.33초 |
| 2차 돌진 | 없음 | 2.33~3.01초 |
| 자세 복귀 | 3.35~4.0초 | 3.01~3.43초 |

인스펙터의 Normal Timeline / Last Stand Timeline에서 각 단계의 **지속 시간**을 바꾼다. Damage / Last Stand Damage와 Distance도 같은 컴포넌트에 있다. 강화의 초기 추적·충전 분배와 마지막 복귀 시간은 지정된 돌진 구간을 만족하도록 구성한 초기값이며 조정할 수 있다.

## 연사 — SkillModule / RapidFire

모든 탄의 전달 피해량은 **10**이다. 일반은 7발, 강화는 기존 12회 × 3방향 = 36발이다. 발사 방향은 충전 시작 때 고정하고 플레이어가 뒤로 가도 바꾸지 않는다. 후퇴는 그 반대쪽으로 최대 3유닛, 최고 속도 2.4로 하며 벽·절벽에 막혀도 발사는 계속한다.

| 항목 | 일반 | 강화 |
| --- | --- | --- |
| 충전 완료 | 1.15초 | 0.5175초 |
| 첫 발사 | 1.2초 | 0.54초 |
| 발사 간격 | **0.32초** | **0.144초** |
| 마지막 발사 | 3.12초 | 2.124초 |
| 회복 시작 | **3.65초** | 약 2.3625초 |
| 회복 시간 | 기존 0.8초 | 0.36초 |

강화의 별도 충전·회복 수치는 주어지지 않아, 간격 비율 `0.144 / 0.32 = 0.45`로 초기 충전과 마지막 발사 후 여유 시간을 압축했다. 12회 발사를 모두 마친 뒤 회복하도록 계산한다. Normal Shot Interval / Last Stand Shot Interval, Charge End Time / First Shot Time / Normal Recovery Start, Recovery Time을 조정하면 된다. 기존의 Firing Duration 필드는 고정 발사 간격 방식으로 대체했다.

충전은 기존 Charge 애니메이션을 끝까지 재생하고 첫 발사까지 마지막 자세를 유지한다. 각 발사의 CrouchFire는 발사 간격에 맞춰 재생해 다음 발사 전에 모션을 마친다.

## 공중 전환 — SkillModule / AirTransition

먼저 Rise로 비행 형태로 변형한 뒤 AirIdle로 상승한다. 기본은 고도 6.5유닛에 도착한 다음 플레이어의 현재 중심을 향해 **1발, 피해 10**의 조준 사격을 한다. 강화는 변형과 상승·사격 시점을 **1.2배 속도**로 진행하고, 상승 시작 시 **5방향 샷건, 탄당 피해 10**을 발사한다. 사격에도 flying up/shot.png의 비행 자세를 사용한다.

Transformation Duration 0.55, Aimed Shot Delay 0.15, Shot Duration 0.4, Last Stand Speed Multiplier 1.2와 Damage를 조정한다. 상승 속도는 루트의 Ascent Speed 2.4이며 강화는 2.88이다. 비행 스프라이트의 PPU와 원점·23 표식·경광등 위치도 맞췄다.

## 사선 레이저 — SkillModule / FanLaser

피해량 **일반 24 / 강화 28**, 횡단당 최대 한 번이다. 강화 회전 속도는 기본의 **1.2배**로 Max Speed 600→720, Min Speed 50→60이다.

강화는 첫 횡단의 페이드·모션 마무리 → Repeat Pause 0.25초 → 반대 방향 두 번째 발사 순서다. **두 번째 경고는 표시하지 않는다.** 쉬는 동안 빔·피해·흔들림은 꺼지고, 실제 발사 중에는 일정한 흔들림을 사용한다. Damage / Last Stand Damage / Last Stand Speed Multiplier / Repeat Pause에서 조정한다.

## 표적 폭격 — SkillModule / TargetBomb

| 항목 | 일반 | 강화 |
| --- | --- | --- |
| 투하 수 | 3 | 6 |
| 피해량 | 22 | 26 |
| 표식 후 폭발 | **1.65초** | **1.15초** |
| 반경 | **75px / 28 ≈ 2.679유닛** | **90px / 28 ≈ 3.214유닛** |
| 첫 표식·투하 | **1.45초** | 약 1.208초 |
| 표식 생성 간격 | **1.05초** | **0.508초** |
| 하강 시작 | **5.5초** | 약 4.583초 |
| 총 진행 시간 | **7.0초** | **5.93초** |

반경은 사용자 확인대로 28 PPU로 환산하며 루트 스케일을 다시 곱하지 않는다. Pixels Per Unit / Normal Radius Pixels / Last Stand Radius Pixels에서 기준과 반경을 조정한다.

최근 플레이어 이동에서 속도를 추정해 **0.35초 정도 앞선 위치**를 겨냥하되, 예측 이동 폭은 최대 1.5유닛으로 제한했다. Prediction Lead / Max Prediction Distance에서 조정한다. 표식이 생성된 후에는 폭탄과 경고 모두 해당 바닥 위치에 고정된다. 큰 축소 원은 실제 비행 진행률을 읽고 폭발 시점에 사라진다. 생성 간격보다 경고 시간이 길어 표식 여러 개가 동시에 보일 수 있다.

폭탄은 기존 위로 솟는 포물선과 BombCharge/Bomb 모션을 사용한다. 비행 시간은 각 탄에 1.65 / 1.15초를 전달한다. EnemyLobProjectile.Launch의 선택 매개변수이므로 기존 다른 적 투척탄은 원래 프리팹 시간을 계속 쓴다. 강화 Bomb 모션은 0.508초 안에 끝나도록 재생 속도를 맞춘다.

폭격 스킬이 하강과 지상 복귀까지 담당한다. FSM이 스킬 종료 후 하강이나 공통 회복을 또 추가하지 않도록 연결했다. 강화의 첫 투하·하강 시작은 일반의 1.2배 진행을 기준으로 두고, 전체 종료는 표의 5.93초를 사용했다. 개별 시간은 인스펙터에서 조정할 수 있다.

## 직접 테스트

1. EnemyTestScene에서 Enemy23과 플레이어를 켜고, 중앙 위 6.5유닛까지 공간과 충분한 바닥을 확보한다.
2. 기본 추적의 약 1.15초 이동·0.9초 충전·1.3초 돌진·0.65초 복귀를 본다. 준비 중 또는 돌진 중 반대편으로 넘어가도 방향이 바뀌지 않아야 한다.
3. 연사 충전 중 뒤로 넘어간다. 방향을 유지한 채 약 1.2초에 첫 탄이 나오고 0.32초 간격으로 총 7발을 쏘는지 확인한다. 보스를 벽에 붙여도 발사는 완료되어야 한다.
4. 공격 준비·돌진·후딜·대기 중 보스를 때린다. HP와 피격 표시만 변하고 밀림·경직·공격 취소는 없어야 한다.
5. 공중 전환에서 먼저 비행 자세가 된 뒤 올라가고, 도착 후 플레이어를 조준하는지 본다. 폭격 표식이 뜨면 이동해 위치가 고정되는지 확인한다.
6. HP를 35% 이하(최대 550 기준 192.5 이하)로 내린다. 진입 편도 레이저 후 강화의 재조준 돌진·36발 연사·상승 샷건·재경고 없는 2연속 레이저·커진 6회 폭격을 본다.

현재 설정 도구는 **SetupBoss23Timeline.Run**이다. 예전 SetupBoss23Rework/SetupBoss23Feedback는 이전 필드·기획을 기준으로 하므로 현재 프리팹에 다시 실행하지 않는다. 검증 도구는 **VerifyBoss23Rework.CheckAssets / RunGround / RunAir / RunFlow**다. 테스트는 EnemyTestScene의 Play Mode에서 수행하며 원본 편집 씬을 저장하지 않는다.

## 사용한 문법과 이유

- **enum + switch**: 추적·충전·돌진·재조준·복귀를 구분한다. 각 단계의 끝 시각을 패턴 시작 시간 기준으로 계산해 타이밍 오차가 누적되지 않게 했다.
- **방향을 float로 저장**: 시작 때 좌우 부호를 한 번 저장하고 탄과 돌진에서 재사용한다. 강화 재조준 구간에서만 다시 읽는다.
- **override와 out bool**: 기존 ModifyIncomingDamage를 재정의해 피해량은 그대로 넘기고 suppressHitControl만 true로 돌려준다. 모든 적의 피격 모듈을 바꾸지 않고 Enemy23의 행동 방해만 막는다.
- **선택 매개변수 float?**: EnemyLobProjectile.Launch에 비행 시간을 선택적으로 넘긴다. 지정하지 않은 기존 호출은 원래 비행 시간을 그대로 사용한다.
- **누적 시간 + 속도 적분**: MoveToDuration이 정해진 시간 안에 목적지에 정확히 도착하도록 빠르게 시작하고 느려지는 곡선을 계산한다. 일반 2.4 이동과 시간 지정 특수 이동을 구분한다.
- **while 발사 스케줄**: 낮은 프레임에서도 이미 지난 예정 발수를 따라잡는다. 간격은 0.32 / 0.144 / 1.05 / 0.508초 값 자체로 유지한다.
- **초기 강화 여부 저장**: 패턴 시작 때 강화 수치와 발수를 고정해 진행 중 HP 변화로 타임라인이 뒤섞이지 않게 했다.
- **기존 애니메이션 길이 / 목표 시간**: PlayForDuration으로 재생 속도를 계산해 충전·발사·복귀 모션을 지정된 동작 시간 안에 마친다. 기능 단위 빈 줄 규칙도 유지했다.
