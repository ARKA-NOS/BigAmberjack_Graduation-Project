# Enemy23 돌진 판정·거리 유지·공중 범위 조정

작업일: 2026-11-24. 기존 패턴 구조·애니메이션·피해량·발사 수·발사 간격을 유지하며 아래 동작을 변경했다.

## 현재 설정

| 위치 | 설정 | 값 |
| --- | --- | --- |
| 보스 루트 / ProductionControlDrone | Air Attack Altitude | **4.5유닛** (이전 5.5) |
| Charge / DroneChargeSkill | Damage Start Ratio | **0.5**: 몸통의 앞쪽 절반부터 피해 판정과 경고 시작 |
| Charge / DroneChargeSkill | Distance | **6.5유닛** |
| RapidFire / DroneSalvoSkill | Preferred Distance | 플레이어와 가로 **3유닛** 간격 |
| RapidFire / DroneSalvoSkill | Distance Tolerance | **0.2유닛**: 목표 근처에서 앞뒤로 떨리는 현상 방지 |
| TargetBomb / DroneBombSkill | Normal Radius Pixels | **52.5px** (75 × 0.7) = 반경 **1.875유닛** |
| TargetBomb / DroneBombSkill | Last Stand Radius Pixels | **63px** (90 × 0.7) = 반경 **2.25유닛** |

공중 공격은 일반·강화가 같은 4.5유닛 높이를 사용한다. 높이는 아레나 바닥에서 보스 루트까지의 거리다. 폭격 예고와 실제 폭발은 같은 축소 반경을 사용한다. 반경과 지름을 0.7배로 줄였으므로 원형 판정의 넓이는 이전의 약 49%가 된다.

## 돌진

이전에는 몸통 전체가 경고와 피해 범위여서 뒤쪽으로 표시가 튀어나왔다. 이제 진행 방향을 기준으로 뒤쪽 절반을 제외한다. 경고·피해 판정에 같은 범위 계산을 사용하므로 표시만 줄여 뒤쪽에서 보이지 않는 피해가 생기는 방식이 아니다. Damage Start Ratio를 0으로 하면 전체 몸통, 0.5면 앞쪽 절반이다.

돌진 준비에 들어갈 때 고정 방향과 Distance로 목적지를 계산해 저장한다. 플레이어의 현재 거리로 돌진 길이를 정하거나, 명중을 이유로 이동을 종료하지 않는다. 강화 두 번째 돌진은 기존 재조준 단계에서 다시 계산한다.

**벽·절벽·아레나 경계에 대한 기존 안전 제한은 유지한다.** 해당 제한이 없는 바닥에서는 항상 6.5유닛을 이동한다. 장애물을 무시하거나 절벽에서 떨어지도록 바꾼 것은 아니다.

## 연사

- 발사 방향은 공격 시작 시 고정한다.
- 발사 중 목표보다 가까우면 뒤로 물러나고, 멀면 앞으로 다가간다. 이동 속도는 기존 보스 MoveSpeed **2.4유닛/초**를 사용한다.
- 기존 비행 이동 모듈의 가감속과 비주얼 보간을 재사용한다. 매 프레임 이동 계획을 다시 시작하지 않으며, 목표 거리로 가는 유효한 이동은 감속까지 마친다.
- 벽·절벽·아레나 경계 때문에 움직이지 못하면 사격만 계속한다.
- 플레이어가 보스의 뒤로 넘어가면 이동을 잠근다. 그 연사가 끝날 때까지 제자리에서 원래 방향으로 발사한다. 플레이어가 다시 앞으로 돌아와도 해당 연사에서는 이동을 재개하지 않는다.
- 다음 공격에서는 이동 잠금을 초기화하고 방향과 거리를 새로 판단한다.

`retreatDistance`는 `preferredDistance`로 바꿨고 `FormerlySerializedAs`를 붙여 기존 프리팹 값을 보존했다. 기존 '3유닛 후퇴' 값은 이제 '3유닛 거리 유지'라는 의미다.

## 직접 테스트

1. `Assets/_Scenes/Test/EnemyTestScene.unity`에서 플레이어와 Enemy23을 켜고 실행한다.
2. 좌우에서 각각 가까이·멀리 서서 돌진을 유도한다. 뒤쪽 절반에 경고가 나오지 않고, 장애물이 없는 곳에서는 시작 위치부터 6.5유닛을 움직여야 한다. 맞은 플레이어 앞에서 멈추면 안 된다.
3. 연사 도중 앞쪽에서 가까워졌다가 멀어져 본다. 보스는 발사 방향을 유지하면서 후퇴·접근해야 한다. 벽 앞에서는 이동 없이 사격해야 한다.
4. 연사 도중 보스의 뒤로 넘어간다. 보스는 멈추고 원래 방향으로 남은 탄을 발사해야 한다. 다시 앞으로 돌아와도 해당 연사가 끝날 때까지 제자리여야 한다.
5. 공중 전환은 바닥 +4.5유닛에서 멈춰야 하며, 포격 표식과 폭발 반경이 이전의 0.7배여야 한다. 강화도 확인하려면 HP를 35% 이하로 낮춘다.

## 검증

EnemyTestScene의 격리 테스트 배치에서 **총 28개 시나리오**를 통과했다. 씬의 기존 오브젝트는 복원했고 씬 파일은 저장하지 않았다. 컴파일·게임 실행 오류는 없으며, 검증용 Play Mode는 종료했다.

- 좌우 × 시작 거리 1.5/9유닛: 뒤쪽 절반 무피해, 앞쪽 명중, 명중 이후에도 **6.5유닛 완주**.
- 기본 연사: 먼 표적 접근, 후퇴 중 표적이 멀어졌을 때 접근으로 전환, 앞뒤 장애물, 뒤로 넘어간 뒤 재등장해도 이동 잠금 유지.
- 기본 7발·7회 섬광, 강화 36발 및 원래 발사 방향 유지.
- 공중 일반/강화 고도 4.5유닛, 폭격 반경 1.875/2.25유닛, 레이저·폭격 판정 및 고정 표식.
- 기존 반격 시간·패턴 선택·35% 발악 진입 흐름.

## 사용 문법과 이유

- **Bounds**: 몸통의 뒤쪽을 제외한 같은 사각형을 경고와 실제 피해 검사에 사용한다. 물리 콜라이더 전체를 변경하지 않고 이 공격의 판정만 좁힌다.
- **필드에 목적지 저장**: 경고 시점에 정한 돌진 목적지를 `_dashDestination`에 보관해 발사 직전 플레이어 이동으로 거리가 바뀌지 않게 한다.
- **`Mathf.Sign`와 부호 있는 거리**: 고정된 발사 방향 기준으로 플레이어가 앞/뒤 중 어디에 있는지와 접근·후퇴 방향을 판단한다.
- **bool 이동 잠금**: 한 연사에서 플레이어가 뒤로 넘어갔다는 사실을 기억한다. 뒤로 갔다 다시 앞으로 오더라도 공격 방향을 뒤집거나 이동을 재개하지 않는다.
- **`FormerlySerializedAs`**: 인스펙터 필드 이름을 변경해도 기존 프리팹에 저장된 숫자를 이어받게 한다.

프리팹 값 연결 도구: `TuneBoss23Spacing.Run`. 검증 진입점: `VerifyBoss23Rework.CheckAssets / RunSpacing / RunGround / RunAir / RunFlow`.
