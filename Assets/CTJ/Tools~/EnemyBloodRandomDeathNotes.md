# 혈흔 5종 무작위 선택과 마지막 피격 후 사망

2026-11-04 정리: 시트 혈흔 5종 원본·프리팹·머티리얼과 관련 제작/검증 도구·캡처는 삭제했습니다. 사망 연출 순서는 유지하며 이 문서는 이전 혈흔의 학습용 기록입니다.

혈흔 표현은 이후 단일 다각형 분사 방식으로 변경했습니다. 최신 설정과 테스트는 [EnemyPolygonBloodNotes.md](EnemyPolygonBloodNotes.md)를 참고하세요. 아래의 사망 순서는 유지합니다.

2026-11-03. `Assets/CTJ` 안에서만 수정했습니다. 확인된 혈흔 원본은 1~5번이며, 사용자 확인에 따라 이 5종을 전부 사용합니다. 이전 EnemyParticleFeedbackNotes.md의 단일 혈흔·즉시 사망 설명보다 이 문서가 우선합니다.

## 적용 결과

- Catto / MadGhost / Enemy01 / Enemy02 / Enemy04 / RobotEyeBoss의 ParticleModule에 혈흔 5종을 연결했습니다.
- 한 타격에 혈흔 하나만 무작위로 선택합니다. 같은 적에서 직전 종류는 제외합니다. 임팩트·슬래시는 기존처럼 별도로 재생합니다.
- `HitBlood.prefab`은 기존 1번, `HitBlood2`~`HitBlood5`는 2~5번 시트입니다. 각각 독립 ParticleSystem과 머티리얼입니다.
- 시트의 프레임 수가 달라 각각 24 / 23 / 28 / 17 / 29칸을 약 60fps로 재생합니다. 재생 시간은 약 0.28~0.48초입니다. 빈 꼬리 부분과 29번 칸에서 다시 나타나는 큰 덩어리를 제외했습니다.
- 마지막 타격에도 넉백·블링크·스케일을 재생한 다음, 기존 사망 애니메이션과 제거 대기로 넘어갑니다. 이동형 적의 넉백 2.5 / 0.2초 설정은 유지했습니다. 터렛·보스의 넉백 끔 설정도 유지합니다.

## 사망 순서

1. 실제 체력이 0이 되면 `IsDead`를 즉시 확정합니다. 추가 피해, AI, 공격 이벤트를 차단하고 공격 스킬을 중단합니다. 공용 NewHealthModule의 OnDead와 보스 체력바 즉시 숨김은 그대로입니다.
2. `IsPlayingDeathReaction` 동안 마지막 타격의 피격 반응을 재생합니다. 피격용 Trigger는 끄고, 지면과 부딪히는 물리 콜라이더는 남겨 넉백이 실제로 이동하도록 합니다.
3. 활성 넉백·경직·블링크·스케일 중 가장 늦게 끝나는 효과까지 기다립니다. 현재 기본 블링크는 약 0.35초입니다. 피격 모듈을 끄면 불필요한 대기는 없습니다.
4. 반응을 복원하고 물리와 나머지 콜라이더를 끈 뒤, Death 애니메이션을 재생합니다. 처치 집계와 코인 생성은 이때 한 번만 처리합니다.
5. 기존 `Death Despawn Delay` 후 오브젝트를 제거합니다. 이 값은 마지막 피격 대기와 별개인 사망 클립용 시간입니다.

이 변경은 눈에 보이는 사망 과정을 늦춥니다. 방 완료 등 외부 코드가 읽는 `IsDead`, 공용 체력의 사망 이벤트는 HP 0 시점이라는 기존 의미를 유지합니다. 피격 정보 없이 NewHealthModule을 직접 호출해 죽이는 관리용 경로는 새 타격 반응을 만들어내지 않습니다.

## Inspector 조정

| 위치 | 조정할 내용 |
| --- | --- |
| 적 → ParticleModule → Hit Effects → Blood (Random 5) → Random Prefabs | 무작위 후보. 다른 혈흔을 추가하거나 불필요한 종류 제거 |
| 같은 항목의 Scale | 해당 적의 혈흔 전체 크기 |
| 같은 항목의 Enabled | 해당 적의 혈흔 끄기 |
| 같은 항목의 Prefab | 후보가 비었거나 전부 None일 때 쓸 기본 효과 |
| 각 HitBlood 프리팹 → Start Size / Start Lifetime | 종류별 크기 / 재생 시간 |
| 적 → HitReactionModule → Blink Duration | 마지막 피격을 포함한 블링크 시간 |
| 적 루트 → Death Despawn Delay | 피격 연출 이후 사망 애니메이션을 보여줄 시간 |

고정 효과로 바꾸려면 Random Prefabs 목록을 비우고 Prefab을 지정하세요. 기존처럼 Prefab만 바꾸면 무작위 후보가 우선합니다. None 항목은 건너뛰며 후보가 하나면 그 하나를 계속 사용합니다.

## 직접 테스트

1. 저장한 테스트 씬에서 Enemy01을 여러 번 공격합니다. 혈흔이 한 번에 하나씩 나오고 바로 직전 모양과 달라지는지 확인합니다. 필요하면 임시로 HP를 높이세요.
2. 마지막 공격 직후 좀비가 약 0.25유닛 밀리고 블링크한 다음 사망 애니메이션으로 넘어가는지 확인합니다. 반응 중 공격을 추가해도 혈흔·처치·코인이 중복되면 안 됩니다.
3. 테스트 인스턴스의 Blink Duration을 0.6초로 잠시 바꾸고, 마지막 블링크가 끝나기 전에 사망 애니메이션이 시작되지 않는지 확인합니다. 끝난 뒤 원래 값을 복구합니다.
4. 터렛/보스는 넉백을 꺼두었으므로 블링크 뒤 사망하는지 확인합니다. 보스 체력바는 HP 0 순간 사라져야 합니다.
5. Random Prefabs를 하나만 남기거나 비웠을 때도 오류 없이 표시되는지 확인합니다. 플레이 중 바꾼 설정을 유지하려면 Play 종료 후 프리팹에 직접 입력하세요.

- 60회 타격에서 5종 모두 등장, 한 타격에 혈흔 하나, 연속 동일 종류 없음. None 후보·단일 후보·빈 목록의 기본 Prefab 사용 통과.

- 적 6종의 피격·마지막 타격·사망 및 파티클 수명, 슈퍼아머, 씬 정리 통과.
- 보스 체력바의 HP 0 즉시 숨김과 공용 `OnHealthChanged → OnDead` 이벤트 순서 유지 확인.
- Unity URP 카메라로 5종을 실제 렌더링해 확인: `EnemyBloodVariants.png`.

## 사용 문법과 이유 — 학습용

### 배열과 Random.Range

`ParticleSystem[] randomPrefabs`는 Inspector에서 여러 프리팹을 넣는 배열입니다. 유효한 후보 수를 센 뒤 `Random.Range(0, count)`로 하나를 선택합니다. 정수형 Random.Range는 최댓값 count를 포함하지 않습니다. 직전 프리팹을 제외한 후보 안에서 균등하게 고르며, 매번 임시 List를 만들지 않습니다.

### NonSerialized

`[NonSerialized] private ParticleSystem _lastPrefab`은 실행 중에만 직전 선택을 기억합니다. 어떤 효과가 마지막으로 나왔는지는 프리팹 데이터로 저장할 설정이 아니기 때문입니다. 적 인스턴스별로 따로 기억합니다.

### IEnumerator / yield return null

`FinishDeathAfterReaction()`은 코루틴입니다. `yield return null`은 메인 스레드를 멈추지 않고 다음 프레임까지 기다립니다. 매 프레임 피격 모듈의 실제 남은 시간을 읽으므로 Blink Duration을 바꾸거나 모듈을 꺼도 고정된 대기 숫자와 어긋나지 않습니다.

### 상태 분리와 중복 방지

`IsDead`는 추가 전투를 막는 상태, `IsPlayingDeathReaction`은 마지막 그림·물리를 재생하는 상태입니다. 하나의 플래그만 사용하면 피격 모듈까지 멈춰 마지막 반응이 잘리므로 둘을 분리했습니다. `_deathFinalized`를 먼저 확인하고 설정해 사망 종료 처리를 한 번만 실행합니다. 새 추상 클래스나 인터페이스는 추가하지 않았습니다.

### Mathf.Max

남은 넉백·경직·블링크·스케일 시간 중 최댓값을 기다립니다. 예를 들어 넉백 0.2초, 블링크 0.35초이면 넉백을 끝낸 위치에서 블링크가 마무리될 때까지 기다립니다. 마지막 반응의 실제 이동 시간까지 늘리는 방식은 아닙니다.
