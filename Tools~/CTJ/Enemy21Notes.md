# Enemy21 절단 공정 자동인형

기획 ID는 `enemy_cutter_automaton`이다. Noctislicer의 대기·달리기·공격·사망 스프라이트를 연결했다. 작업용 장갑판과 고정 볼트는 별도 픽셀 스프라이트로 표현했고, 피격 시에는 기존 플래시와 금속 파편을 사용한다. [09-21 절단 공정 자동인형 기획서](https://app.notion.com/p/09-21_-4189e7231ca781429b52fffdcb8e753a)

체력 100, 방어 4, 이동 속도 3.4유닛/초, 경직 0.2초, 표준 넉백의 65%로 설정했다. 9유닛 안에서 추격하고, 13유닛 밖으로 벗어나면 스폰 지점으로 복귀한다. 처치 시 코인으로 9~14골드를 떨어뜨리고 기존 처치 집계와 금속 파편 버스트를 사용한다.

직선 돌진 베기는 준비를 시작한 위치와 방향을 기준으로 3.8유닛의 경로를 고정한다. 0.65초 동안 경로를 예고하고, 돌진 중 플레이어에게 닿으면 16 피해를 한 번 준 뒤 경로 끝까지 이동한다. 벽이나 끊긴 바닥에 닿으면 그 앞에 정지한다. 이동과 베기 클립이 모두 끝난 뒤 0.85초 후딜에 들어가며, 3.4초 쿨타임은 타격 시점을 기준으로 계산한다. 빗나가면 돌진 종료 시점부터 계산한다.

`GroundDashSlash`의 **Maximum Consecutive Dashes** 기본값은 1이다. 2로 바꾸면 첫 돌진과 베기가 끝난 뒤 사거리와 지상 조건을 다시 확인하고, 조건을 만족할 때 두 번째 3.8유닛 돌진을 시작한다. 돌진 속도는 11유닛/초, 공격 가능한 발 높이 차이는 0.55유닛이다.

기획의 경험치 20은 지급 시스템을 찾지 못해 연결을 보류했다. 1스테이지 절단 공정의 실제 배치는 남아 있다.

## 직접 테스트

1. `EnemyTestScene`의 평평한 발판에 Enemy21을 배치한다. 가까이에서 맞았을 때와 경로 밖으로 피했을 때 모두 적이 출발점에서 3.8유닛 이동하는지 본다. 예고 중 반대편으로 넘어가면 처음 예고 방향으로 돌진한다.
2. 벽과 발판 끝에서 적을 유도한다. 이동 구간이 막히거나 바닥이 끊기면 그 앞에서 멈추는지 본다.
3. 연속 횟수를 2로 설정한 뒤 첫 베기 직후 다시 사거리 안에 선다. 두 번째 예고가 보이며, 최대 2회 뒤 0.85초의 후딜에 들어간다. 코인은 활성 `GameManager`가 있는 씬에서 확인한다.

## 사용한 문법과 이유

- `enum Phase`로 준비·돌진·베기·후딜을 나눴다. `ControlsMovement`가 참인 돌진 구간에서만 스킬이 Rigidbody2D의 수평 속도를 설정한다.
- `const float AttackDistance`에 고정 거리 3.8을 둔다. 공격 시작 조건, 경고 길이, 이동 끝점을 같은 수치로 계산한다.
- 매 `FixedUpdate`에서 지형이 허용한 이동 구간만큼 `Physics2D.OverlapBox`로 공격을 검사한다. 타격 여부는 다음 피해 검사를 생략하는 데 쓰고, 이동은 남은 거리와 지형으로 계산한다.
- `BeginPreparation()`으로 같은 스킬의 준비 절차를 다시 호출해 두 번째 예고에도 같은 타이머와 정리 코드를 사용한다. 현재 베기 클립의 `normalizedTime`이 1 이상일 때 다음 예고나 후딜을 시작한다.
