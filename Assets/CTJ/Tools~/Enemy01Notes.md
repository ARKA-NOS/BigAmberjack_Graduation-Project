# 09-01 팔이 뒤틀린 사람 — Catto 임시 비주얼

## 결과와 범위

- 새 프리팹: `Assets/CTJ/Prototypes/Prefabs/Enemy01_TwistedArm.prefab`
- 전용 스탯: `Assets/CTJ/Prototypes/Stats/Enemy01_TwistedArm_Stats.asset`
- 전용 스킬 키: `Assets/CTJ/Prototypes/Skills/Enemy01_TwistedArm_Melee.asset`
- 기존 Catto 프리팹·애니메이션·스탯은 변경하지 않았습니다. 복제한 프리팹에서 기존 Visual/Animation Event/스킬/피격/보상/처치 집계를 사용합니다.
- 노션과 동료 폴더는 수정하지 않았습니다. 방 데이터에 새 프리팹을 등록하거나 기존 맵 씬에 배치하는 작업도 수행하지 않았습니다.

타이머는 프레임 단위로 처리되므로 소량의 프레임 지연이 있을 수 있습니다. 총 준비 시간을 바꾸려면 스탯과 Post Blink Delay의 합을 조절하세요. 경고 종료부터 실제 피해까지 Catto 클립의 0.05초가 추가됩니다. 후딜과 쿨타임은 별개입니다.

## 룸 중심과 배회 범위

`PatrolModule`의 `EnemyPatrolModule`에서 설정합니다.

1. `Center Override`가 지정되어 있으면 해당 고정 앵커를 중심으로 사용합니다. 움직이는 적 자신/자식은 중심으로 사용할 수 없습니다.
2. 없으면 적의 부모 계층에서 `RoomDefinition`을 찾습니다. 좌우 Portal Point가 모두 있으면 두 위치의 중점을 사용합니다.
3. 룸에 포털 정보가 없으면 룸 Transform 원점, 룸 자체가 없으면 적의 초기 생성 위치를 사용합니다.
4. `Center Offset X`는 이 중심을 좌우로 보정합니다.
5. `Half Width`는 중심에서 한쪽까지의 **월드 거리**입니다. 적의 스케일에 따라 배회 폭이 바뀌지 않습니다. 0으로 설정하면 배회하지 않습니다.

현재 SDW 생성기는 Instantiate 때 룸을 부모로 지정하므로 자동 연결됩니다. 수동 배치할 때도 적을 룸의 자식으로 넣으세요. 단순히 룸 근처에 놓기만 하고 계층상 부모가 아니면 소속 룸을 알 수 없습니다.

배회는 지상 좌우 이동이며 여러 층을 탐색하는 길찾기가 아닙니다. 벽·낭떠러지를 발견하면 멈춰 대기한 뒤 반대 방향 목적지를 선택합니다. 중심 범위는 적 루트 X 좌표 기준이며, 몸체 폭까지 포함한 공간 크기는 아닙니다.

배회 범위는 **추격 범위를 제한하지 않습니다.** 추적 해제 후 범위를 벗어나 있다면 배회 구간 쪽으로 걸어와 배회를 재개합니다. 개별 스폰 지점으로 귀환하는 로직은 없습니다. 지형이 막혀 있으면 순간이동하거나 점프해서 복귀하지 않습니다.

## 수동 테스트 순서

1. 현재 씬을 저장한 뒤, 새 프리팹을 지면 위에 배치합니다. 지면은 EnemyMovement의 Terrain Layers(현재 Ground)에 포함되어야 합니다.
2. 룸 자동 중심을 보려면 `RoomDefinition`이 붙은 오브젝트의 자식으로 넣습니다. 단독 테스트에서는 `Center Override`에 빈 오브젝트를 지정해도 됩니다.
3. Scene 뷰 Gizmos를 켜고 `PatrolModule`을 선택합니다. 청록색 선과 양 끝 표시가 배회 구간이며, 전체 폭 숫자도 표시합니다. Half Width를 바꿔 확인하세요.
4. Play에서 플레이어가 탐지 거리 밖에 있을 때 구간 안을 걷고 잠시 멈추는지 확인합니다. 벽·발판 끝에서는 방향을 바꿉니다.
5. 플레이어를 가까이 가져가면 추적, 공격 범위에서는 정지해야 합니다. 다시 해제 거리 밖으로 나가면 룸 기준 배회를 재개해야 합니다.
6. 공격 준비 마지막에 Catto가 단색 빨강으로 0.2초 표시되고, 원래 색으로 돌아온 뒤 타격해야 합니다. 실제 타격 시 전방 Hitbox와 겹쳐 있을 때만 피해 8이 들어갑니다.
7. 붉은 경고 중 적을 때려 공격이 취소되고, 피격 점멸 종료 후 원래 색으로 돌아오는지 확인합니다. HP 50이 소진되어야 사망합니다.
8. 기존 Gold/처치 수까지 보려면 활성 CurrencyManager(Gold 등록)와 EnemyKillCountManager가 있는 환경에서 테스트합니다. 없는 격리 씬에서는 해당 기존 모듈의 경고가 발생할 수 있습니다.

## 사용 문법과 이유 — 학습용

- `Module` 상속과 `override Initialize(ModuleOwner owner)`: 공용 모듈 등록 순서에 맞춰 적·이동·피격 모듈 참조를 얻습니다. 새로운 기반 클래스나 인터페이스는 추가하지 않았습니다.
- `[SerializeField] private`, `[Min]`, `[Tooltip]`: 외부 코드에서 무분별하게 값을 바꾸지 않으면서 Inspector에서 수치를 설정하고 의미를 확인하게 합니다. 실제 계산에서도 Mathf로 범위를 제한합니다.
- `GetComponentInParent<RoomDefinition>()`: 생성된 적이 어느 룸의 자식인지 확인합니다. 모든 룸을 전역 검색하거나 가장 가까운 룸을 임의로 고르지 않습니다. 동료 컴포넌트의 공개 읽기 API만 사용합니다.
- `Random.Range()`와 `Mathf.Lerp()`: 좌우 목적지를 번갈아 정하되 매번 정확히 같은 끝점까지 걷지 않도록 이동 거리에 변화를 줍니다.
- `Time.time`과 `FixedUpdate`: 목적지 대기는 시간으로 측정하고 Rigidbody 이동은 FSM의 물리 업데이트에서만 처리합니다. 별도 코루틴이 추격과 동시에 이동시키지 않습니다.
- `out bool blocked`: 이동 함수의 방향 반환값과 별개로, 지형 때문에 멈췄는지를 배회 모듈에 전달합니다. 벽에 도착했을 때 목적지를 바꾸는 데 사용합니다.
- `Physics2D.BoxCast`와 `ContactFilter2D`: 기존 지형 검사 코드를 재사용해 벽과 앞쪽 바닥을 확인합니다. 플레이어·다른 적·트리거를 지형으로 판단하지 않습니다.
- `sharedMaterial` 참조 교체: 기존 단색 피격 머티리얼로 스프라이트 윤곽을 완전한 빨강으로 채웁니다. 머티리얼 에셋 자체를 수정하거나 매번 새 머티리얼을 복제하지 않습니다.
- `[DefaultExecutionOrder(100)]`: 공격 경고의 LateUpdate를 피격 점멸보다 뒤에 처리합니다. 피격 모듈이 원본 색을 저장하기 전에는 경고를 먼저 복원하여, 나중에 빨간색이 원래 색으로 남지 않게 합니다.
- `#if UNITY_EDITOR`와 `OnDrawGizmosSelected`: 에디터에서만 범위와 라벨을 표시합니다. 플레이어 빌드에 UnityEditor 참조가 들어가지 않습니다.
- 선택적인 모듈 참조의 null 검사: 배회/공격 경고 모듈이 없는 기존 Catto·MadGhost·보스는 기존 동작을 유지합니다.

## 검증

- Unity 프로젝트 컴파일 오류 없음.
- 편집 모드: 스크립트 누락, 스킬/경고/Hitbox/Animator/스탯 참조, HP/피해/쿨타임/점프, 포털 중점·룸 원점·직접 앵커·단독 배치 중심 확인.
- 격리 Play: 룸 기준 배회와 폭 변경, 추격/해제, 벽/낭떠러지 반전, HP 50·피해 8, 0.2초 붉은 경고 후 타격, 중복 타격 방지, 쿨타임, 피격 취소 및 색 복원, 취소를 끈 경우의 경고/피격 겹침, 사망 정리, 기존 Catto의 제자리 대기 확인.
- 검증 중 사용자 씬은 저장하지 않습니다. 빈 임시 씬에서 실행하고 원래 CTJ_MapTestScene을 다시 엽니다.
- 자동 검사는 동작·시간·색/머티리얼 상태를 확인합니다. 실제 아트의 가독성과 게임에서 느껴지는 이동 속도는 위 수동 순서로 최종 조정하세요.

`BuildEnemy01.cs`는 최초 생성 도구이며 기존 결과가 있으면 덮어쓰지 않습니다. 테스트 도구는 `VerifyEnemy01.cs`이고, 둘 다 Unity 자동 컴파일에서 제외되는 기존 `Tools~` 규칙을 따릅니다.
