# Enemy23 강화 연사 중첩·정지 사격 호버링

2026-11-25.

## 원인과 수정

강화 연사의 한 발사 회차는 원래부터 0도·12도·24도에 한 발씩 **3발**이었다. 12회 발사하므로 전체 수는 **36발**이다. 한 회차에 9발을 만드는 반복문은 없었다.

다만 스케줄이 늦어지면 기존 `while`이 밀린 발사 회차를 같은 프레임에 처리했다. 테스트에서 발사 스케줄을 0.5초 늦어진 상태로 만들어 확인하자 한 프레임에 3회·9발이 생성됐다. 실제 CPU를 멈추거나 게임에 지연 코드를 넣은 것이 아니라, 격리 테스트의 발사 시간 필드를 과거로 조정해 기한 초과 상황을 재현했다.

이제 한 프레임에 한 회차만 실행하고, 실제 발사 시각에 간격을 더해 다음 발사를 예약한다. 강화는 프레임당 최대 3발이며 밀린 회차를 몰아서 생성하지 않는다. 전체 회차 수는 유지하므로 프레임이 심하게 늦어지면 공격 전체 시간은 조금 늘어날 수 있다.

앞뒤 총구도 월드 좌표로 약 1.765유닛 떨어져 있었다. 강화탄이 한 간격 동안 이동하는 거리는 15 × 0.144 = 2.16유닛이라, 총구를 교대하면 일부 탄의 간격이 약 0.4유닛까지 가까워져 쌍처럼 보일 수 있었다. 강화탄은 앞쪽 기준 총구 하나에서 생성하도록 통일했다. 앞뒤 런처의 발사 애니메이션 교대는 유지한다. 일반 연사는 기존 총구 교대와 무작위 높이를 유지한다.

호버링은 기존에 수평 이동 중에만 켜졌다. 플레이어가 뒤로 넘어가 이동이 잠기면 이 조건도 꺼졌다. 이제 **첫 발사 이후부터 후딜 전까지 사격 중인지**를 기준으로 호버링과 비행 배기를 유지한다. 뒤로 넘어간 플레이어를 따라 회전하거나 이동하지 않으며, 고정된 위치와 방향으로 사격하면서 비주얼만 위아래로 움직인다. 벽에 막혀 제자리에서 쏘는 경우에도 적용된다.

## 조절 위치

- `SkillModule/RapidFire / DroneSalvoSkill`: Normal Shot Interval 0.32초, Last Stand Shot Interval 0.144초, Normal Volleys 7회, Last Stand Volleys 12회, Last Stand Spread Angle 12도.
- `DroneVisualModule`: Salvo Hover Height 0.18, Salvo Hover Amplitude 0.1, Salvo Hover Frequency 2. 사격 중 시각적 높이·진폭·빈도를 조절한다. 물리 몸통의 높이는 바꾸지 않는다.

## 직접 테스트

1. `EnemyTestScene`에서 Enemy23이 일반 연사를 시작하도록 한다. 사격 도중 보스 뒤로 이동한다.
2. 보스는 수평 이동과 방향 전환을 멈춘 채 남은 탄을 원래 방향으로 쏘고, 상하 호버링과 배기는 계속되어야 한다. 사격 후딜에 들어가면 부드럽게 기본 높이로 내려와야 한다.
3. HP를 35% 이하로 낮추고 발악 진입을 마친 뒤 강화 연사에서도 같은 과정을 확인한다. 한 회차에 세 방향으로 한 발씩 나와야 한다. 앞뒤 런처의 모션은 번갈아 재생된다.
4. 벽 때문에 이동할 수 없는 위치에서도 제자리 사격의 호버링이 유지되는지 확인한다.

## 검증 결과

EnemyTestScene Play Mode의 격리 배치에서 일반/강화 × 좌/우 교차 4개 경우와 일반/강화 × 이동/벽 막힘 4개 경우를 검증했다.

- 수정 전: 회차당 3발·전체 36발은 맞지만, 지연 조건의 프레임당 최대 생성 수가 9발이었다. 뒤로 넘어간 뒤 호버 블렌드 최솟값은 0이었다.
- 수정 후: 강화는 모든 회차가 정확히 3발, 전체 36발, 지연 조건에서도 프레임당 최대 3발이었다. 각 회차의 각도는 0/12/24도다.
- 강화 발사점과 앞쪽 기준 총구 사이 오차는 0이었다. 일반 연사는 기존 높이 무작위 범위 0.3유닛을 유지했다.
- 뒤로 넘어간 뒤 일반·강화, 좌·우 모두 수평 위치와 발사 방향을 고정했다. 사격 중 호버 블렌드는 1을 유지하고 상하 이동 범위는 약 0.2유닛이었다.
- 벽 막힘에서도 호버링과 배기를 확인했다. 일반 7회/7발·강화 12회/36발, 앞뒤 발사 모션 7/12회 교대, 탄당 피해 10, 마지막 발사 모션 뒤 기본 자세·후딜 전환을 유지했다.
- 원본 결과: `Boss23SalvoAuditBefore.json`, `Boss23SalvoAuditAfter.json`, `Boss23SalvoRegression.json`.

## 문법과 이유

- **`while` 대신 `if`**: 기한이 지난 발사를 한 프레임에 여러 번 실행하지 않도록 한 회차만 처리한다.
- **다음 실행 시각 저장**: `_nextVolleyAt = Time.time + _interval`로 직전 실제 발사부터 간격을 보장한다. 별도 타이밍 시스템은 추가하지 않았다.
- **조건 연산자 `?:`**: 강화에서는 기준 총구, 일반에서는 교대 총구를 선택한다. 발사 수와 방향 계산은 기존 반복문을 사용한다.
- **조건 속성 `IsSalvoFiring`**: 수평 이동 여부와 사격 표시를 분리했다. 기존 `Mathf.MoveTowards` 블렌드와 사인파 호버링을 재사용한다.
