# 적 피격 피드백 — 2026-10-18

수정 범위는 Assets/CTJ만이다. 공용 DamageData/Agent/HealthModule/플레이어/물리 설정은 수정하지 않았다. 새로운 패키지나 인터페이스/추상 클래스 없이 기존 Module을 상속한 선택 컴포넌트 `EnemyHitReactionModule`을 사용한다.

최신 정정: **Catto도 피격 시 진행 중인 근접 공격을 취소**한다. 피격 색은 틴트 곱셈이 아니라 **무늬·검은 윤곽까지 모두 단색 빨강으로 채우는 전용 셰이더**로 표시한다. 실루엣의 투명한 부분과 원래 알파는 유지한다.

## 현재 동작

| 설정 | Catto | Mad Ghost |
| --- | --- | --- |
| Enable Knockback | 켬 | 켬 |
| Knockback Speed / Duration | 5.1 / 0.18초 | 5.1 / 0.18초 |
| Enable Blink / Duration | 켬 / 0.35초 | 켬 / 0.35초 |
| Blink Interval / Hit Color (RGB) | 0.05초 / (1, 0, 0) | 0.05초 / (1, 0, 0) |
| Hit Material | EnemySolidHitFlash | EnemySolidHitFlash |
| Cancel Attack On Hit | 켬: 근접 준비·타격·회수 취소 | 켬: 준비·차징 취소 |

- 유효한 양수 피해로 HP가 줄고 살아 있을 때 실행한다. 0/음수/NaN/무한대 피해, 이미 죽은 적에는 반응하지 않는다. HP 0이 되는 피해는 사망 연출을 우선한다.
- 수평 초기 속력 5.1에서 0으로 0.18초간 감속한다. 최초 속력 3에서 **1.7배**로 높였으며 넉백 시간은 유지했다. 평지의 명목 이동량은 약 0.27 → 0.459 월드 단위이며 물리 프레임/마찰/벽에 따라 달라진다. 기존 Y 속도와 중력은 건드리지 않고 Ground 충돌을 유지한다.
- 넉백 동안 FSM의 상태 갱신/이동 입력과 새 공격 시작을 잠깐 막아 추적·공격의 속도 설정이 넉백을 덮어쓰지 않게 한다. 종료 후 기존 FSM 동작을 재개한다. 밀리는 동안 걷기 애니메이션을 켜지 않는다.
- 밀리는 방향은 가해자(Dealer)로부터 멀어지는 수평 방향이 우선이다. 방향을 구할 수 없으면 DirectedKBForce.x → hitDirection.x → 현재 타깃 반대쪽 → 오른쪽 순서다. 현재 플레이어 평타의 전달 방향에 의존해 가해자 쪽으로 당겨지는 것을 피한다. 피해 데이터의 힘 크기를 그대로 적용하지 않고 적 모듈의 속력/시간으로 작은 밀림을 조절한다.
- 깜빡임은 **단색 빨강 ↔ 원래 모습**이다. 0.35초 동안 교대하며 **투명도는 원래 알파를 그대로 유지한다.** 피격 순간에만 전용 머티리얼로 참조를 교체하고 원래 머티리얼로 되돌린다. 머티리얼 에셋 자체나 스프라이트/애니메이션 속도는 수정하지 않는다. 공격 예고 Canvas 점멸과는 별개이므로 Catto에도 피격 깜빡임이 있다. Inspector의 Hit Color로 다른 적의 피격 색을 조절할 수 있다.
- **무적 시간은 없다.** 깜빡이는 동안 다시 맞아도 HP가 줄고 피격 시간이 갱신된다. 속도를 더해서 누적하지 않으며 원래 색과 알파도 보존한다.
- Mad Ghost는 준비·예고 점멸·점멸 후 유지 단계 중 맞으면 스킬과 예고 UI를 즉시 취소한다. 이미 발사된 탄은 유지하고 발사 후 회수 동작은 취소하지 않는다. 쿨타임은 기존 준비 시작 시각 기준을 그대로 유지하며, 넉백과 쿨타임이 끝나야 다음 공격을 할 수 있다.
- Catto는 준비/타격/회수 중 피격되면 즉시 스킬을 취소하고 Idle 모션으로 복귀한다. 취소 뒤 늦게 전달된 타격 이벤트도 무시한다. 이미 적용된 피해는 되돌리지 않고, 준비 시작 기준 쿨타임도 초기화하지 않는다. 보스 등의 공격을 유지하려면 Cancel Attack On Hit을 끈다.
- 사망, 적/모듈/게임 오브젝트 비활성화 시 넉백을 끝내고 원래 색과 머티리얼을 복원한다. 이 피격 모듈이 없는 기존 적은 기존 방식대로 피해/사망을 처리한다.

## 재사용·보스·추가 효과

1. CTJ 내부의 새 적/Prefab Variant 루트에 EnemyHitReactionModule을 하나 둔다. 기존 두 프리팹의 Variant는 이미 상속받는다. 공용 ModuleOwner가 초기화 시 수집하므로 실행 중 새 모듈 장착 기능은 별도로 만들지 않았다.
2. Sprites에는 피격 표시할 비주얼 SpriteRenderer만 넣고 Hit Material에 `Prototypes/Sprites/EnemySolidHitFlash.mat`을 연결한다. Sprites를 비워두면 시작 때 자식 SpriteRenderer를 찾는다. Canvas나 투사체는 연결하지 않는다. 기본 두 프리팹은 두 참조 모두 연결되어 있다. Hit Material이 없으면 색 연출만 생략하고 피해·넉백·공격 취소는 유지한다.
3. 보스에서 밀리지 않게 하려면 Enable Knockback을 끈다. 공격을 유지하려면 Cancel Attack On Hit을 끈다. 색 변화가 필요 없으면 Enable Blink도 끈다. 각각 독립적이며 모두 꺼도 피해는 받는다. 컴포넌트 전체를 비활성화해도 된다.
4. 추가 음향/파티클은 **기존 EnemyBase(표시 이름은 Melee Enemy/Ranged Enemy)의 On Hit UnityEvent**에 AudioSource.Play, ParticleSystem.Play 같은 함수를 연결한다. 별도의 미래용 효과 프레임워크는 만들지 않았다. OnHit는 유효한 피해마다 호출되며 사망을 유발한 피해에서도 호출된다. 살아 있을 때만 필요한 추가 효과는 연결한 수신 함수에서 IsDead를 확인한다.
5. HP·공격 준비 시간은 기존 Stats, 이동/피격 속력과 깜빡임은 각 모듈 설정이다. 임의의 새 보스 패턴/저항 스탯은 이번에 만들지 않았다.

## 직접 테스트

1. Play를 종료한 뒤 컴파일을 기다린다. `CTJ_MapTestScene`에서 실제 PlayerTestPack으로 두 적을 좌우에서 때린다. 가해자 반대쪽으로 이전보다 약 1.7배 멀리 밀리고, 약 0.35초간 단색 빨강/원래 모습을 번갈아 보여야 한다. 피격 빨강 구간에는 검은 몸체나 눈의 원래 색이 남아 있으면 안 된다. 실루엣 바깥이 빨간 사각형으로 채워지거나 투명도가 낮아져서도 안 된다. 기본 평타 10이면 HP는 여전히 Catto 4회, Ghost 3회에 0이 된다.
2. Ghost의 경고 경로가 보일 때 공격한다. 경고가 바로 사라지고 해당 준비에서 탄이 발사되지 않아야 한다. 충분히 기다리면 다음 공격은 다시 가능하다. 발사된 뒤 때리면 기존 탄은 사라지지 않아야 한다.
3. Catto가 준비 자세를 잡았을 때 때린다. 준비가 풀리고 그 공격의 피해가 들어오지 않아야 한다. 타격 동작 중/공격 후 회수 중 피격도 남은 동작을 취소한다. 이미 먼저 들어온 피해는 취소되지 않는다. Catto의 범위 UI는 계속 없어야 하며, 적과 플레이어가 서로 밀거나 막지는 않아야 한다.
4. 벽 옆에서도 공격한다. 적이 Ground 벽을 뚫거나 바닥으로 떨어지지 않아야 한다. 낭떠러지 밖으로 밀리면 기존 중력으로 떨어지는 것은 정상이다.
5. 테스트 인스턴스의 Enable Knockback / Enable Blink / Cancel Attack On Hit을 하나씩 꺼 차이를 확인한다. 마지막 옵션을 끈 Catto는 피격되어도 공격을 유지해야 한다. 보스 시험은 세 옵션을 모두 끄고 HP만 감소하는지 확인한다. Play 중 설정을 원본 프리팹에 Apply하지 않는다.
6. 플레이어 없이 검사하려면 EnemyArtTest에서 적 컴포넌트 메뉴의 `Test/Take 2 Damage (Play Mode)`를 사용한다. 이 씬의 Probe는 적을 자동으로 공격하지 않는다. 메뉴를 연속 사용해 HP 감소와 원래 색 복원을 확인한다. 피격 중 적을 비활성화했다가 활성화해도 붉은색이 남지 않아야 한다.

## 검증

`Tools~/VerifyEnemyHitReaction.cs`의 ValidatePrefabs와 RunScenarios를 사용한다. 기존 InspectEnemyArt.BeginPlayTest / StopPlayTest / RestoreStartScene 흐름으로 CTJ 전용 테스트 씬을 열고 복제본만 검사한다. 씬/프리팹을 저장하지 않는다.

피격 검사 22건: 좌우 밀림/가해자 방향 우선/추적 속도 덮어쓰기 방지, 연타 HP 감소와 단색 피격/알파 보존/색·머티리얼 복원, 준비 3단계의 Ghost 취소, 이미 발사된 탄 유지, Catto 준비·타격·회수 취소와 취소 옵션 끄기, 효과별 옵션/기존 OnHit 확장, 사망·비활성화·재활성화, 벽/바닥/무효 피해/방향 대체, 선택 모듈 제거 호환, 두 적 각각 이전 속력 3과 새 속력 5.1의 단발 이동 거리 비교.

`Tools~/VerifyEnemyHitRendering.cs`의 RunScenarios는 실제 URP 카메라로 두 적을 그려 알파 1/0.6 두 조건을 확인한다. 각 조건의 가시 픽셀 15,704개가 전부 빨강이며 알파 변경 0, 효과 종료 후 원본 렌더 픽셀과 완전히 일치했다. 원본이 어두운 몸체/분홍 눈의 2색 팔레트라 초기 테스트의 4색 이상 가정만 바로잡았다. 게임 셰이더는 그 과정에서 변경하지 않았다. `Tools~/EnemyHitOriginal.png`, `EnemyHitSolidRed.png`는 이 카메라의 원본/피격 순간 캡처다. 확인을 위해 테스트 복제본에서 점멸을 길게 유지했으며 실제 0.35초의 영상은 아니다.

기존 원거리 스킬 검사의 1.05초 고정 대기는 준비·유지·탄 이동이 프레임 경계에 걸려 한 차례 실패했다. 실제 명중/후딜 완료를 기다리고 1.6초 상한 및 기존 쿨타임을 확인하도록 검증 코드만 보완했다. 실제 게임 공격 시간은 바꾸지 않았다.
